# navichno.in.ua

Односторінковий сайт сервісу **navichno** — сайти пам’яті та QR-коди на пам’ятники. Історія життя, фото й спогади відкриваються одним наведенням камери на QR-код, у будь-якому місці й через багато років.

Статичний сайт без збірки та залежностей: HTML, CSS і ванільний JavaScript.

## Структура

```
index.html              сторінка (uk)
css/style.css           усі стилі, 15 розділів (див. нижче)
js/main.js              інтерактив: тема, меню, слайдер, прев’ю оформлення
assets/icons/           favicon
assets/images/qr.webp   QR-код для hero-сцени
```

`css/style.backup.css` — локальна страховка перед рефакторингом, у git не потрапляє (`.gitignore`).

## Запуск

Збірки немає. Відкрийте `index.html` у браузері або підніміть будь-який статичний сервер:

```sh
python3 -m http.server 8000
# http://localhost:8000
```

## Стилі

`css/style.css` розкладено за розділами, у кожного селектора одна фінальна версія:

1. Змінні теми та базові правила
2. Типографіка й кнопки
3. Загальний контейнер
4. Header і мобільне меню
5. Hero
6. Секція «Як це працює»
7. Формати й таблиця
8. Оформлення
9. Що всередині
10. FAQ
11. Контакти
12. Footer
13. Адаптив: планшет (`≤1100`, `≤1024`, `641–1024`, `≤900`, `≤860`)
14. Адаптив: мобільний (`≤640`, футер `≤560`)
15. `prefers-reduced-motion`

Правила роботи з файлом:

- Нове правило додавайте у відповідний розділ, а не в кінець файлу. Медіазапити живуть тільки в розділах 13–14.
- Не правте існуючий селектор другим блоком нижче, змінюйте його єдиний блок.
- Без `!important`. Єдиний виняток — розділ 15.
- Інлайнових `style=""` у HTML немає, для одиничних відступів створюйте модифікатор на кшталт `.lead--tone`, `.sec-head--faq`, `.swatch--olive`.

### Тема

Кольори задані CSS-змінними на `:root`. Темна тема за замовчуванням, світла вмикається двома шляхами:

- `:root[data-theme="light"]` — вибір користувача, зберігається в `localStorage` під ключом `navichno-theme`;
- `@media (prefers-color-scheme: light)` — системна тема, якщо користувач нічого не обирав.

Основні змінні: `--bg`, `--bg-2`, `--card`, `--text`, `--muted`, `--line`, `--accent`, `--accent-ink`, `--cream`, `--cream-ink`, `--foot-bg`.

### Hero-сцена

Сцена `.flow` використовує `container-type: inline-size`, тому всі розміри каменя, телефона й сторінки задані в `cqw` і масштабуються разом з контейнером. Анімації: пунктирна лінія `dash`, підсвітка QR `qrglow`, сканер `scan`, погойдування сторінки `pagein`.

## JavaScript

`js/main.js` — одна IIFE без залежностей. Поведінка прив’язана до `data-*` атрибутів, тому класи можна змінювати без правок JS:

| Хук | Що робить |
| --- | --- |
| `[data-theme-toggle]` | перемикає `data-theme` на `<html>`, пише в `localStorage` |
| `[data-burger]`, `[data-mnav]`, `[data-mnav-close]`, `[data-mnav-link]` | мобільне меню, `Escape` закриває, фокус повертається на бургер |
| `.plans` + `[data-plans-dots]` | крапки-навігація для слайдера форматів на планшеті й мобільному |
| `[data-more]`, `[data-more-label]` | розгортання блоку «Що всередині» на мобільному |
| `[data-mode]`, `[data-tone]`, `[data-preview]`, `[data-tone-name]` | прев’ю оформлення: 5 кольорів × 2 теми, палітри в об’єкті `tones` |
| `#top` | клас `scrolled` на шапці після прокрутки |

Класи, на які JS спирається: `open` (меню, features), `lock` (body), `scrolled` (header).

## Адаптив

- `> 1024` — десктоп: 4 картки форматів, hero-сцена праворуч від тексту.
- `641–1024` — планшет: меню ховається за бургер (`≤900`), формати стають горизонтальним слайдером, hero-сцена під текстом.
- `≤ 640` — мобільний: hero по центру, формати по одній картці на екран, «Оформлення» компактне з прев’ю між текстом і перемикачами, «Що всередині» згорнуте.

Шапка й меню враховують `safe-area-inset` для iPhone з вирізом.
